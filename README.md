A 5-7-5 haiku about debugging: a cursor blinking at three in the morning, a log line that lies, and a bug that wore my name. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

> three a.m. cursor
> blinks at a log line that lies
> the bug wore my name

## Run it

```sh
python3 main.py
```

`main.py` writes the haiku to `/output/entry.txt` (creating `/output` if needed). Nothing else runs: no network, no secrets.
